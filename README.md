# KD 2027 Responsive Calendar

기존 사이트: https://kd-2027-calendar.kd-visual.workers.dev/

## 반영 내용

- 기존 표지 및 12개월 영상, 월별 키워드·설명을 유지했습니다.
- 기존 최대 520px 고정 너비를 없애고 화면 너비·높이에 반응하는 레이아웃을 적용했습니다.
- PC는 영상과 UI를 좌우로, 휴대폰 세로 화면은 영상과 UI를 상하로 배치합니다.
- 휴대폰 가로 화면은 좌우 배치로 바뀌며, 설명은 세로로 스크롤할 수 있습니다.
- 패널은 흰색, 기본 타이포그래피는 검정, 월 선택 및 버튼 눌림은 #3E74FF입니다.
- PC 월 선택은 6열·2행, 휴대폰은 좌우 스크롤 방식입니다.
- 모든 월 화면에 ‘나비엔 하우스 바로가기’를 추가했습니다. https://www.navienhouse.com/ 을 새 창으로 엽니다.
- 이전·다음, 좌우 방향키, 영상 영역 스와이프, 재생·일시정지, 콘셉트 팝업을 제공합니다.
- ?m=1부터 ?m=12까지 월별 직접 접근이 가능합니다.
- 모션 줄이기 설정에서는 영상 자동 재생을 끕니다.
- 키보드 포커스, 팝업 Escape 닫기, 화면 읽기용 이름을 적용했습니다.

## 미리보기 및 배포

별도 빌드나 패키지 설치가 필요 없는 정적 사이트입니다. 이 폴더를 정적 웹 서버로 제공하면 됩니다.

예: Python이 설치된 환경에서 이 폴더를 기준으로 `python3 -m http.server 8765`를 실행하고 http://localhost:8765/ 를 엽니다.

실제 배포 파일은 index.html, styles.css, app.js, data.js, cards.js, card-data.js, favicon.svg, assets 폴더입니다. assets의 상대 경로를 유지하세요. 기존 Cloudflare 서비스의 배포 방식으로 이 파일들을 올릴 수 있습니다. 이번 작업에서는 기존 운영 주소에 배포하지 않았습니다.

## 원본 영상과 반응형 범위

UI와 영상 컨테이너는 화면 크기에 맞게 재배치됩니다. 원본 영상은 1080×1920 세로 비율이며, 영상 안에 들어 있는 날짜와 그래픽은 한 장면으로 함께 축소·확대됩니다. 날짜를 잘라내지 않기 위해 object-fit: contain으로 원본 비율을 유지했습니다. 영상 내부의 날짜·그래픽 위치를 기기별로 별도 재배치하려면 레이어 분리 또는 가로형 모션 원본 제작이 필요합니다.

## 검증

브라우저에서 320×568, 390×844, 768×1024, 1024×768, 1440×900, 1920×1080 및 844×390 화면을 확인했습니다. 12개월 선택, 표지 이동, 콘셉트 팝업, 재생 제어, 링크 대상 및 선택 색상을 점검했습니다. 월 선택 영역의 의도된 스크롤 외에 페이지 가로 넘침은 없습니다. 실제 iOS·Android 기기 테스트는 별도입니다.


## 메시지 카드 업데이트

- care_source의 KD Calendar-01.png는 표지, 02~13.png는 1~12월에 대응합니다. 제공된 원본 PNG를 변경 없이 사용합니다.
- 이미지 737×539px + 메시지 영역 737×539px = 최종 737×1078px PNG입니다. 두 영역은 메시지 길이와 관계없이 같은 크기로 고정됩니다.
- Pretendard로 최대 200자까지 입력하며 글 크기와 줄바꿈을 자동 조정합니다. 월별 문구는 페이지를 열어둔 동안 유지됩니다.
- 심볼은 메시지 하단 고정 위치에 표시합니다. 1월과 3월만 컬러, 표지를 포함한 나머지는 화이트입니다.
- 상단 문구는 Optimizing Around You, 회사명은 KyungDong이며 2027 버튼으로 표지를 볼 수 있습니다.
- 모든 월에 나비엔 하우스 바로가기가 있습니다.
- Pretendard 라이선스는 assets/fonts/OFL.txt에 포함했습니다.
- 13개 이미지 원본 일치, 월별 연결과 로고 설정, 200자 제한, 737×1078 캔버스 및 동일한 두 영역 높이를 검증했습니다.
